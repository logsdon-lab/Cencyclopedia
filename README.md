## Getting Started
Setup dependencies. Requires Python >= 3.12.
```bash
python -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
```


## Run locally
### Python
Set up app locally. Data is stored in repo.
```bash
python -m cencyclopedia.app
```
